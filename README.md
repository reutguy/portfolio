- הטקסטים בנויים בלי טענות על לקוחות, קמפיינים או ניסיון. הוסיפי קרדיט צילום לכל תמונה כשיש.
- טופס יצירת הקשר הישן לא הועבר: לאתר סטטי אין שרת. יש טלפון, וואטסאפ, אינסטגרם ופייסבוק.
